# Silo Agent Application

Silo Agent is a cross-platform application built with [nstudio/electron](https://github.com/nstudio/xplat) for seamless integration with the Silo Business Suite.

---

## Prerequisites

- [Node.js](https://nodejs.org/) (version 20 or later recommended)
- [Yarn](https://yarnpkg.com/) (package manager)
- [nstudio/electron](https://github.com/nstudio/xplat)
